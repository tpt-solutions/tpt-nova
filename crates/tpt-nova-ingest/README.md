# tpt-nova-ingest

> Smart mesh ingestion for TPT Nova: .glb/.obj loading, VHACD convex decomposition, procedural auto-rig, and Rapier3D collider generation

Smart mesh ingestion: glTF/OBJ loading, V-HACD convex decomposition, procedural auto-rigging, and Rapier3D collider generation.

Part of [TPT Nova](../../README.md), the AI-native, ECS-based real-time engine.

## Workspace dependencies

- `tpt-nova-ecs`
- `tpt-nova-anim`

## Testing

```sh
cargo test -p tpt-nova-ingest
```
