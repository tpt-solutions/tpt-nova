# tpt-nova-neural-materials

> Live video-LLM neural material feeds: API contract + streamed frame-to-texture mapping for TPT Nova

Live video-LLM neural material feeds: a transport-agnostic frame-source contract plus streamed frame-to-texture upload over wgpu.

Part of [TPT Nova](../../README.md), the AI-native, ECS-based real-time engine.

## Workspace dependencies

- `tpt-nova-ecs`

## Testing

cargo test -p tpt-nova-neural-materials
