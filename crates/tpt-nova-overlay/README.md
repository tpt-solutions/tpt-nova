# tpt-nova-overlay

> Highlight & Fix viewport overlay tooling for TPT Nova: select a screen region and generate an AI fix prompt

"Highlight & Fix" viewport overlay logic: region selection, entity picking, and assembly of AI fix prompts. Fully testable without a GPU.

Part of [TPT Nova](../../README.md), the AI-native, ECS-based real-time engine.

## Workspace dependencies

- `tpt-nova-ecs`

## Testing

```sh
cargo test -p tpt-nova-overlay
```
