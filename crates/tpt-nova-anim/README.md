# tpt-nova-anim

> Skeletal animation: skinning, keyframe sampling, pose blending, and a simple animation state machine for TPT Nova

Skeletal animation: skinning matrices, keyframe sampling, pose blending, and a small animation state machine.

Part of [TPT Nova](../../README.md), the AI-native, ECS-based real-time engine.

## Workspace dependencies

- `tpt-nova-ecs`

## Testing

```sh
cargo test -p tpt-nova-anim
```
