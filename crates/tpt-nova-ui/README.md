# tpt-nova-ui

> Immediate-mode 2D UI for TPT Nova: panels, buttons, and text emitted as a renderer-agnostic draw list

Immediate-mode 2D UI that emits a renderer-agnostic draw list of panels, buttons, labels, and text input. Pure logic, so it is unit-testable without a GPU.

Part of [TPT Nova](../../README.md), the AI-native, ECS-based real-time engine.

## Testing

```sh
cargo test -p tpt-nova-ui
```
