# tpt-nova-editor

> TPT Nova scene/level editor v1: hierarchy, component inspector, 2D gizmos, and the Vibe GUI curve editor

Framework-agnostic scene editor logic: hierarchy, component inspector, 2D and 3D gizmos, multi-select with undo/redo, and the Vibe GUI curve editor.

Part of [TPT Nova](../../README.md), the AI-native, ECS-based real-time engine.

## Workspace dependencies

- `tpt-nova-ecs`
- `tpt-nova-physics`
- `tpt-nova-ui`

## Testing

```sh
cargo test -p tpt-nova-editor
```
